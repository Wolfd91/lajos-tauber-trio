# Lajos Tauber Trio — website

De website van het Lajos Tauber Trio. Alles zit in één bestand: `index.html`.

## Bekijken
Dubbelklik op `index.html` → het opent in je browser.

## Aanpassen
Open `index.html` in een teksteditor (bijv. [VS Code](https://code.visualstudio.com/),
gratis) en pas de teksten aan. Bovenin het bestand, bij `:root`, kun je makkelijk
de kleuren wijzigen.

## Samenwerken (twee pc's, via GitHub)

**Eenmalig, op elke pc:**
1. Zorg dat [Git](https://git-scm.com/download/win) geïnstalleerd is.
2. Haal het project op:
   ```
   git clone <repo-url>
   ```

**Telkens als je gaat werken:**
1. Haal eerst de laatste versie op:
   ```
   git pull
   ```
2. Maak je wijzigingen in `index.html`.
3. Sla op en stuur ze door:
   ```
   git add .
   git commit -m "korte uitleg van je wijziging"
   git push
   ```

> Tip: begin altijd met `git pull` zodat je de wijzigingen van de ander binnenhaalt
> vóór je zelf iets aanpast. Dat voorkomt botsingen.

## Online
De site staat live via GitHub Pages (de link verschijnt in de repo onder
*Settings → Pages*).
